## 六章展示结构

1. **历史演进**：年份改变时读取当年的具体事件；早期保留里程碑，不给每年填造一个发现。
2. **材料路线**：五种电解质并列，看材料指标、工作条件、优势与制造约束。
3. **论文数据拆解**：把能量密度层级、温度、压力、载量、容量和寿命终点拆开，避免简单纪录榜。
4. **国内外企业**：分类、已发生进展、验证阶段和未来目标分别显示；企业披露不冒充独立实测。
5. **政策与市场**：发布/实施日期分列；新型储能总体规模只作应用背景，不标为固态装机。
6. **固定储能适配**：回答汽车样品之外，还需要怎样证明电站安全、净效率、寿命、成本和规模制造。

## 这一轮最有价值的五组解释

- **聚合物的温度代价**：离子输运改善要看相态和升温条件；70°C的小容量软包不能用作室温Ah级产品证明。
- **材料电导到器件之间的缺口**：粉末电导、复合正极有效通路、固/固界面接触与完整封装电芯分别是什么问题。
- **2020三星研究的不同层级**：小样循环、不同层数下的含封装计算值、制造压力、运行压力不可合为一颗“全部纪录同时实现”的电芯。
- **2024/2025温度、外压与寿命**：6000次必须同时见55°C和25MPa；运行无外压不等于制造无需600MPa；运行1000圈与80%容量门槛寿命不同。
- **“固态”名称的实际差别**：半固态交付、陶瓷固态分隔膜与全固态样品是不同进度；汽车、材料厂、电站应用也不能互相代替。
