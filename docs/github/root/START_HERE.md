# Start here

This is **Energy Research Copilot**, a local-first energy-storage research and learning Web application.

1. Read `AGENTS.md`, `CURRENT_STATUS.md`, and `TEST_REPORT.md` for repository rules, release scope, and checks recorded so far.
2. Read the root `README.md` and `docs/github/SETUP.md` to run the app.
3. For a feature change, inspect only its relevant frontend/backend source and related docs before planning. Preserve existing workflows and the accepted homepage.
4. Keep secrets, local databases, uploaded papers and private analysis out of Git. Use `.env.example` for configuration examples.
5. Use one targeted check for a material behavior change and report exactly what was checked.

The default user library is empty on a new install. Public interface assets and research teaching materials are part of the application. The app is a responsive Web application; native mobile apps and multi-user public hosting are future work.
