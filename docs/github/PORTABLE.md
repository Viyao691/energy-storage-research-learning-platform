# Windows 便携安装包

便携版通过本机启动器运行应用，并在本机浏览器打开界面。使用时下载 Windows x64 ZIP，解压到可写目录，再双击其中的 `启动.cmd`。启动后保持弹出的控制台窗口开启；关闭窗口会停止本机应用。

解压目录中的 `data` 目录用于保存个人数据库、上传文件和其他资料。首次运行该目录为空，应用会在其中创建个人资料；请保留此目录，备份或迁移时复制整个目录。

运行基础功能不需要另装 Docker、Python 或 Node。默认 Mock 模式可用于演示；连接真实模型、使用语义检索或 OCR 时，需自行配置相应模型服务，并按需准备 OCR 权重。模型服务和权重不包含在便携包内。

Docker Compose 方式面向从源码进行开发和构建的使用者，见[源码开发安装与运行方式](SETUP.md)。
