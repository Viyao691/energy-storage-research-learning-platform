# 从论文到学习与研究

平台把一篇个人论文的阅读证据带到学习包、数据整理和实验设计中。处理由用户发起，分析结果需对照论文和数据复核。

## 论文阅读与复习

1. **上传 PDF**：导入自己有权使用的 PDF。系统读取可用的标题、作者、期刊等书目信息；缺失时可在论文页面补齐。
2. **基础解析**：先提取 PDF 文本与页码，用于搜索和阅读。论文记录会区分全文、摘要或仅元数据，避免把摘要结果说成全文分析。
3. **按需增强**：文本层质量较差时，可在系统设置确认下载本地 OCR 模型，并从论文详情运行 OCR。Docling 是可选解析器；需图像理解时可配置视觉模型并明确选择页面。
4. **核对证据**：阅读报告和问答可回到对应页码与片段查看。AI 归纳、规则结果和原文依据会区分展示；使用者应核对实验条件、图表和上下文。
5. **建立学习包**：从已有论文创建学习包，生成或编辑知识卡片，自测后手动确认掌握状态并安排复习。论文后续解析不会改写已保存学习包中的证据快照。
6. **整理封面**：论文库卡片会从 PDF 前 8 页最多 40 张嵌入图片中选择适合的封面图；无合适图片时回退到平台主题插画。插画是示意素材，不代表论文原图。没有本地 PDF 的摘要或元数据记录不提取封面。

## 数据与科研想法

1. 导入 CSV 或 XLSX，选择工作表并查看列、单位和来源。
2. 检查缺失值、数据条件和必要参数，确认后运行应用内固定统计或科研配方；结果用于辅助分析，不替代原始记录。
3. 在“科研想法”中选择希望引用的论文证据或数据分析，再写研究问题、假设与验证路径。
4. 编辑并保存九项实验设计，查看审查提示后人工修改。导出 Markdown、Word 或分页 PPT；数值计算/分析 ZIP 可在 Python 3.12 及以上环境中按包内说明重新运行。

已保存的实验设计可单独删除。删除想法时，确认框会显示关联实验设计数量，确认后一起删除；来源论文和数据集保留。

科研想法和模型提出的候选内容需要人工核对数字、条件、跨表对应关系和可行性。系统不会因为文本生成成功就证明科学结论正确。

## 其他学习入口

- **储能编年史**：25 条路线共用历史、材料、论文、企业、政策市场、储能适配六栏目；各主题内容标注来源。
- **储能城市应用**：教学示意图讲解八类典型城市能源场景和三种工况。图示用于学习场景关系，不是城市实测或项目设计数据。
- **校园资讯**：连接西安交通大学公开校园资讯来源并提供整理入口；来源登录、限流或网络不可用时以实际结果为准。
